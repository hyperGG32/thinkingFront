# GenericCTF — фронтенд

Мінімальний фронтенд для CTF-платформи GenericCTF у ретро-хакерському стилі: матриця, анонімуси, зелений текст на чорному тлі.

Працює окремо від бекенду, на іншому порту, і отримує дані з REST API через `fetch`.

Стек: HTML + CSS + чистий JavaScript, без залежностей і без збірки.

## Сторінки

- `index.html` — список задач для всіх: пагінація, фільтри, сортування, деталі задачі.
- `register.html` — реєстрація; після успіху одразу логін і перехід у бункер.
- `login.html` — логін (JWT).
- `lair.html` — «секретний бункер», лише для авторизованих:
  - створити задачу (чернетку);
  - свої задачі: надіслати на рев'ю, видалити;
  - лише для адміна: модерація задач (схвалити/відхилити) і нова категорія.

## Авторизація

- токени зберігаються в `localStorage` (`access_token`, `refresh_token`) і передаються в хедері
  `Authorization: Bearer <access>`;
- access прострочився (`401`) — фронтенд сам бере новий через `POST /auth/token/refresh/` і
  повторює запит; користувачу логінитись знову не треба;
- refresh теж прострочився — токени видаляються; на приватній сторінці перенаправлення на логін;
- logout — видалення обох токенів з `localStorage` і перехід на головну;
- неавторизованого користувача з `lair.html` перенаправляє на `login.html?next=lair.html`, після
  логіну — назад;
- авторизованого користувача з `login.html` і `register.html` перенаправляє в бункер;
- у навігації: неавторизований бачить «Увійти» і «Приєднатися», авторизований — своє ім'я і
  «Вийти»;
- `?next=` приймає лише сторінки цього сайту, щоб не можна було перенаправити на чужий.

Спільна логіка (API, токени, навігація) — у `common.js`.

## Адреси та порти

- фронтенд: `http://localhost:5500` (або `http://127.0.0.1:5500`)
- бекенд: `http://127.0.0.1:8001/api/v1`

Адреса бекенду задана на початку `common.js` у константі `API_URL`.

## Як запустити проєкт

1. Запустіть бекенд з репозиторію [thinking](https://github.com/hyperGG32/thinking) на порту 8001
   (інструкція — у його README):
   ```
   python manage.py runserver 8001
   ```
   Для модерації і категорій потрібен адмін: `python manage.py createsuperuser`.
2. У теці фронтенду запустіть статичний сервер:
   ```
   python -m http.server 5500
   ```
3. Відкрийте `http://localhost:5500` у браузері.

Якщо бекенд не запущено або CORS не налаштовано, у терміналі на сторінці з'явиться `ACCESS DENIED`.
