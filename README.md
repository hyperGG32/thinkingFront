# GenericCTF — фронтенд

Мінімальний фронтенд для CTF-платформи GenericCTF у ретро-хакерському стилі: матриця, анонімус у худі, зелений текст на чорному тлі.

Фронтенд працює окремо від бекенду, на іншому порту, і отримує дані з REST API через `fetch`. Це показує, що CORS на бекенді налаштований правильно.

Що вміє:

- список задач з пагінацією;
- фільтри за назвою, категорією та складністю, сортування;
- деталі задачі в модальному вікні при кліку на картку;
- помилки API показуються в «терміналі» на сторінці.

Стек: HTML + CSS + чистий JavaScript, без залежностей і без збірки.

## Адреси та порти

- фронтенд: `http://localhost:5500` (або `http://127.0.0.1:5500`)
- бекенд: `http://127.0.0.1:8001/api/v1`

Адреса бекенду задана на початку `app.js` у константі `API_URL`.

## Як запустити проєкт

1. Запустіть бекенд з репозиторію [thinking](https://github.com/hyperGG32/thinking) на порту 8001:
   ```
   py manage.py runserver 8001
   ```
   У бекенді вже дозволені origin `http://localhost:5500` і `http://127.0.0.1:5500` (`CORS_ALLOWED_ORIGINS`).
2. У теці фронтенду запустіть статичний сервер:
   ```
   python -m http.server 5500
   ```
3. Відкрийте `http://localhost:5500` у браузері.

Якщо бекенд не запущено або CORS не налаштовано, у терміналі на сторінці з'явиться `ACCESS DENIED`.
